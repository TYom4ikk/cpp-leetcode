##1. Two Sum
Стоит задача перебрать вектор и найти те числа, сумма которых будет равна значению target.
Так как перебор идёт в рамках 1 вектора, я решил брать по одному числу 0...n (по индексам) и складывать их
с перебираемыми числами 0...n (по индексам). Таким образом получалось что я беру 1-е число и складываю его с 1-ым, 2-ым, 3-ым...n-ым, затем беру 2-е число и складываю его с 1-ым, 2-ым, 3-ым...n-ым, итд.
В процессе я пропускаю сравнивание одних и тех же чисел(стр. 8). Числа, сумма которых совпала с target идёт в финальный вектор.

##9. Palindrome Number
Есть число. нужно определить палиндром ли это. Сразу отсеиваем отрицательные числа, которые не могут быть палиндромом. Далее я перевожу int в string, чтобы было проще работать с конкретными разрядами. В строке размера n я сравниваю символы с противоположных концов. первый с последним, второй с предпоследним итд.
если хоть что-то не совпало, то return false. в противном случае всё завершается return true.

##37. Sudoku Solver
Нужно создать "Решатель Судоку". Функция bool solve нужна, чтобы решать и перерешивать новые состояния "доски". "Доска" 9x9. обычный O(n²) вложенный цикл. Пропускаем все не пустые клетки. И в пустых клетках начинается перебор цифр от 1 до 9. Проверяется, попадается ли эта цифра в строке, столбце, квадрате 3x3. Если где-то она уже попалась, начинается перебор следующей цифры. Если цифра не попалась ни в строке, ни в столбце, ни в квадрате 3x3, то ставим её в текущую пустую клетку. И снова запускаем solve.
В судоку есть правило. Если на 1 клетку подходят несколько цифр, то нужно выбрать единственный правильный вариант. Я сделал так - ставим первый подходящий вариант. результат solve (true или false) отражает найдено ли решение. если false, то значит с подставленной цифрой решить судоку не получилось, поэтому убираем её из клетки и пробуем следующую цифру. (Если для пустой клетки не подошла ни одна цифра, возвращается false, чтобы вернуться назад и попробовать изменить предыдущую поставленную цифру. Если пустых клеток больше нет, возвращается true.)

##112. Path Sum
Нужно узнать равен ли любой путь от root до leaf значению targetSum.
Изначально дана структура TreeNode.
Поиск leaf от root происходит рекурсивно. Создается переменная treeSum которая будет хранить сумму всего путя. Изначально к treeSum добавляется значение root, затем если у root есть левый путь - снова запускается функция, пока не достигнет leaf. после левого пути проверяется и правый путь. Если мы достигли leaf и сумма всех звеньев равна targetSum - возвращается true.

##113. Path Sum II
Нужно найти ВСЕ пути от root до leaf, сумма которых равна targetSum. В отличие от 112 задачи здесь нужно не просто вернуть true/false, а сохранить сами пути, поэтому создается финальный двумерный вектор result и временный вектор path, который хранит текущий путь.
Поиск leaf от root происходит рекурсивно, как и в 112 задаче. Создается переменная treeSum, которая хранит сумму текущего пути. Изначально к treeSum добавляется значение root, а само значение root добавляется в path. Затем если у текущего node есть левый путь - снова запускается функция, после чего проверяется правый путь. Когда функция доходит до leaf, проверяется равна ли treeSum значению targetSum. Если да, текущий path добавляется в result. После выхода из node его значение удаляется из path через pop_back().
